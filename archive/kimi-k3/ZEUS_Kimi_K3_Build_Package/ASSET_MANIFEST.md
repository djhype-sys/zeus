-   `assets/ZEUS_MASTER_LOGO_REFERENCE.jpg` Main ZEUS brand logo going
    forward. Preserve the Z + lightning-bolt-as-E + U + S composition
    and brushed aged-gold/dark-rustic material language.

-   `assets/ZEUS_MOBILE_UX_REFERENCE.png` Primary Dark/Oracle mobile UX
    art direction. Use the giant lightning orb, Zeus statue, storm
    environment and minimized navigation as the signature experience.

## Supporting references

-   `assets/ZEUS_DESKTOP_ORACLE_REFERENCE.jpg` Earlier desktop
    Oracle/management concept. Use for hierarchy and broader system
    inspiration, not as a requirement to reproduce every element.

-   `assets/ZEUS_LOGO_TRANSPARENT_REFERENCE.png` Isolated logo reference
    useful for UI placement. Check transparency/masking before

## Important

The logo supplied in ZEUS_MASTER_LOGO_REFERENCE.jpg is the brand
authority if any visual references conflict. Do not redraw the logo into
a different wordmark unless necessary for responsive sizing; preserve
its core geometry and lightning-E concept.
